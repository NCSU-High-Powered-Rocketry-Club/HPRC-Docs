# Software

## Getting Started

Install these tools before working on Payload software:

1. [Git](https://git-scm.com/downloads) - version control for the project.
2. [uv](https://docs.astral.sh/uv/getting-started/installation/) - installs and runs Python dependencies.
3. [Visual Studio Code](https://code.visualstudio.com/download) - the recommended IDE (but if you want to use a different one, that's fine too).

### VS Code extensions

Install these extensions from the VS Code Extensions tab:

1. [Python](https://marketplace.visualstudio.com/items?itemName=ms-python.python) by Microsoft
2. [autoDocstring](https://marketplace.visualstudio.com/items?itemName=njpwerner.autodocstring) by Nils Werner
3. [Rainbow CSV](https://marketplace.visualstudio.com/items?itemName=mechatroner.rainbow-csv) by mechatroner
4. [Even Better TOML](https://marketplace.visualstudio.com/items?itemName=bungcip.better-toml) by bungcip
5. [Remote - SSH](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-ssh) by Microsoft

These extensions are either required or very helpful to have for developing Python code for the Payload software.

### Github

Make a Github account if you don't have one already, **don't use your school email or Github account**. If you're confused at the relationship between Git and Github, watch [this video](https://www.youtube.com/watch?v=-Xfch1DV9Vk).
